# Card Draw App

A mobile-first, app-style companion to the Card Reference tool, built for drawing cards at the table during gameplay testing.

- Swipe or tap between three tabs: Win Condition, Team Event, Player Event — each is its own full-screen deck.
- Each tab shows the current draw and a big Draw button sized for thumbs.
- The Player Event tab draws two cards at once and displays both side by side, since Player Events are assigned individually to each GM.
- Weighted draws and reshuffle behavior match the main reference tool.

Open `index.html` directly, or serve this directory as a static site.
