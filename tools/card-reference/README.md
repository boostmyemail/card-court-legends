# Card Reference & Draw

A single-file, static HTML tool for Card Court Legends gameplay testing.

- Draws random cards from the Win Condition, Team Event, and Player Event decks, weighted by real print-run odds.
- Full rules-text reference grid for every card, kept in sync with current wording.
- No build step or dependencies — it's one self-contained `index.html`.

Open `index.html` directly in a browser, or serve this directory as a static site.
